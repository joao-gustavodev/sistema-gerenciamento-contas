# 🎧 Meu Projeto de Helpdesk

Este é o meu primeiro sistema de helpdesk! Criei este projeto para praticar desenvolvimento de software e construir um sistema simples de abertura e controle de chamados de suporte.

## 📌 O que o sistema faz?

- Permite cadastrar um novo chamado de ajuda.
- Exibe uma lista com todos os chamados abertos.
- Permite alterar o status do chamado (ex: "Em Aberto" ou "Concluído").
